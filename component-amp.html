HXJ8002 amplifier + 40 mm speaker

The pet's voice — 5 wires · the only module on 5 V · big difference between the two boards

What it is. The ESP32 can only produce a tiny signal, far too weak to drive a speaker. The HXJ8002 is a small class-D amplifier that takes that signal and pushes real current into an 8 Ω speaker. It is the only module in the whole pet that runs on 5 V — everything else is 3.3 V.

2. Diagram — pin locations

DevKit — GPIO25 DAC

GPIO25 is the real hardware DAC — it outputs a clean analog wave, so tones sound smooth rather than buzzy.

Mini / C3 — GPIO6 PWM

The C3 has no DAC at all. GPIO6 sends a PWM square wave instead — louder and buzzier, but perfectly usable for beeps and simple melodies.

3. DAC vs PWM — the important difference

Normal DevKit — true analog output

// GPIO25 is a real DAC: write 0..255 for a clean analog level
#define SPK_PIN 25

// soft sine-ish "chirp" for a happy sound
for (int i = 0; i < 200; i++) {
  int v = 128 + (int)(100.0 * sin(i * 0.08));
  dacWrite(SPK_PIN, v);
  delay(8);
}

ESP32 Mini / C3 — PWM tone (no DAC)

// No DAC on C3: use LEDC PWM to make a square-wave tone
#define SPK_PIN 6
#define TONE_CH 0

void setupTone() {
  ledcSetup(TONE_CH, 2000, 8);   // channel, freq Hz, 8-bit
  ledcAttachPin(SPK_PIN, TONE_CH);
}

void tone(uint16_t freq) {
  ledcWriteTone(TONE_CH, freq);  // 0 = silence
}

Pick a frequency per note (e.g. 523 for C5, 659 for E5) and call tone(freq). Use tone(0) for silence.

Watch out — 5V is the one module on 5V.
  • Power the amp from 5V / VIN / VBUS. Never from 3V3 — it will sound weak or not work at all, and overdrive it.
  • Common ground is mandatory. The amp GND must be the same GND as the ESP32 GND. If they are separate, the audio signal has no reference and you get nasty hum or nothing.
  • Do not connect the speaker across V1 and V2 with anything else — no capacitor, just the two wires to the cone terminals.
  • On C3 boards, confirm the 5V pad is a real 5V rail and not 3V3. If unsure, power the amp straight from the USB 5V line.
  • A capacitor across the speaker terminals (+ to −, 100 nF) reduces crackle on the volume changes. Optional.
Test. Wire the amp and speaker only (ESP32 can stay disconnected) and touch the L pin with a small screwdriver — you should hear a buzz. That confirms the amp and speaker work before you debug any code.

4. Speaker mounting

The 40 mm speaker sits at the upper back wall of the housing, held by the printed mounting ring. The back has a circular perforated grille in front of it so sound gets out while the housing keeps its solid sides. Route V2 (+) and V1 (−) to the two speaker terminals.
