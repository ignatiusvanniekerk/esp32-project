3. Power notes

USB 5 V → ESP32 VIN (5 V)
ESP32 on-board LDO → 3V3 rail (sensors, OLED, motor)
5 V rail → HXJ8002 VDD (amplifier needs the headroom)
GND is common to every module  —  single black star to the ESP32 GND
Why 3V3 for the vibration motor: the 1027 D03A is a 3 V coin-style motor; driving it from 3 V3 keeps spin speed sane and current below the LDO limit. The 1N4007 plus the BC337 protects GPIO27 from back-EMF spikes.

4. Code first-lines

Wire.begin(21, 22);                 // I2C: OLED
  pinMode(32, INPUT);                  // TTP223 touch input
  U8g2 oled(U8G2_R0, U8X8_PIN_NONE);   // or Adafruit_SSD1306
  ledcSetup(0, 5000, 8); ledcAttachPin(27, 0);   // motor PWM
  analogRead(35);                      // mic envelope
  ledcWriteTone(0, 0);                 // HXJ8002 L on GPIO25 via dacWrite(25, …)

Caveats: GPIO35 is input-only (fine for the mic). Feed the TTP223 at 3V3, not 5 V, so its output can never exceed the ESP32’s 3.3 V logic. DAC (GPIO25) gives ~0–3.3 V into the HXJ8002’s DC-coupled input — start with a small amplitude.
