MAX4466 microphone

Analog mic amplifier — 3 wires · hears claps and voice · output goes to an input-only pin

What it is. An electret microphone with a small amplifier built in. The MAX4466 boosts the tiny analog signal from the mic capsule up to a 0–3.3V swing the ESP32 can read on an ADC pin, which is how the pet notices claps or speech.

2. Diagram — pin locations

DevKit — GPIO35 (input only)

GPIO35 is on the right row and is input-only — it can read the mic but can never be used as an output. That is exactly what we want here.

Mini / C3 — GPIO2 (ADC1)

On the C3 the ADC pins are ADC1 = GPIO0–GPIO4. Stay off ADC2 (GPIO5) — WiFi uses it and readings there are unreliable.

3. Sketch pins

Normal DevKit

#define MIC_PIN 35

analogRead(MIC_PIN);   // 0 .. 4095

ESP32 Mini / C3

#define MIC_PIN 2

analogRead(MIC_PIN);   // 0 .. 4095

4. Gain trim

The MAX4466 has a small onboard trimmer (blue pot with a screw slot) that sets how loud the output is. With the pet quiet you will probably need to turn it clockwise to pick up claps from further away. Turn it a little at a time — too far and it picks up motor buzz.

Watch out.
  • OUT must go to an input-only / ADC1 pin. Wiring it to a strapping pin like GPIO0 or GPIO2 on some boards can prevent booting.
  • Keep the mic wire short and away from the motor wires — motors are electrically noisy and will show up as a loud hiss.
  • Read the baseline first (pet sitting quiet), then trigger a reaction when the value jumps well above it. A fixed threshold is noisy.
Test. Flash a sketch that prints analogRead(MIC_PIN) to the Serial Monitor and clap once. The number should spike and settle back down.
