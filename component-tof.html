VL53L0X ToF sensor

Time-of-flight distance sensor — 4 wires on the same I2C bus as the OLED · sits behind the 14 × 10 mm panel window

What it is. A laser time-of-flight ranger. It measures how far an object is in millimetres using reflected light, with no touching involved. The pet uses it to notice when you put a hand or a cup in front of its face.

2. Diagram — shared I2C bus

The OLED and the ToF plug onto the same two wires. One SDA line, one SCL line, both modules hanging off them. Each module has its own I2C address, so they answer separately.

3. Sketch pins

Normal DevKit

#define SDA_PIN 21
#define SCL_PIN 22
#include <Wire.h>
#include <VL53L0X.h>

VL53L0X sensor;
Wire.begin(SDA_PIN, SCL_PIN);
sensor.setXSHUT(true);

ESP32 Mini / C3

#define SDA_PIN 8
#define SCL_PIN 9
#include <Wire.h>
#include <VL53L0X.h>

VL53L0X sensor;
Wire.begin(SDA_PIN, SCL_PIN);
sensor.setXSHUT(true);
Watch out.
  • XSHUT / SHUT pin. Some ToF breakout boards carry a 5th pin (XSHUT or SHUT). If yours has one, tie it to 3V3 so the sensor powers up when the board does. Leave it unconnected on boards without it.
  • Address conflict. Two VL53L0X modules on one bus clash. You only have one, so this is fine — but if you add a second, it needs an XSHUT line to wake them one at a time.
  • Distance range. Useful roughly 30–2000 mm. Too close and it reads zero.
Test. Run the ToF sketch alone. Print the millimetre reading to the Serial Monitor and wave a hand in front of the sensor — the number should move.
