Every module, one page each — pin locations, wire colours and diagrams for both the normal ESP32 DevKit and the ESP32 Mini / C3 · powered by USB 5 V

Read this first. Build one module at a time and test before adding the next. Never put 5 V into a 3V3 pin — the amplifier is the only module on 5 V; everything else is 3.3 V. All modules share one common ground.

3. Build order

1. OLED only → 2. add ToF (shares I2C) → 3. add mic → 4. add touch → 5. amp + speaker → 6. motor. Upload and verify each sketch before moving to the next.

Safety. All modules share one common ground. Power the amp from 5 V but tie its GND to the board GND. Do not back-feed 5 V into the 3V3 rail. Disconnect USB before rewiring the motor or amp. Never drive a motor directly from a GPIO pin.
