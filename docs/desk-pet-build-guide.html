Desk Pet — Build Guide & Parts List

Smart interactive desk companion · ESP32 2.8″ touchscreen (CYD) · v1 desk model (no wheels)

1. The idea in one picture

Your 2.8″ ESP32 board is the Cheap Yellow Display (CYD, ESP32-2432S028). The screen is mounted forward inside a 3D-printed shell so it becomes the pet’s face (animated eyes / mascot). The touchscreen responds to taps and petting, the speaker sits behind a grille, and the vibration motor is glued to the inside of the shell so the whole body shivers when the pet is happy. USB-C powers it out of the back/bottom.

What the pet does

  • Screen touch → reacts when tapped or “petted”
  • Sound sensor → reacts to claps and loud talk
  • Speaker (on-board amplifier) → pet sounds
  • Vibration motor → purr / shiver when you pet it or it gets excited
  • USB-C → power from PC or charger (no battery in v1)

Pin budget (why it fits): the CYD exposes GPIOs 21, 22, 27, 35 for add-ons. The touch is built into the display, motor = 27, sound = 35. The old INMP441 needed 3 pins (SCK/WS/SD) which would not fit; the analog sound sensor needs only 1.

5. Build steps

  1. Flash/verify the CYD first: Install Arduino core for ESP32, select “ESP32 Dev Module”, run one of the CYD example sketches (TFT_eSPI has a CYD user setup; XPT2046_Touchscreen for touch). Confirm screen + touch + USB-C work before anything else.
  2. Motor driver circuit on protoboard: solder transistor, 1 kΩ + 10 kΩ resistors, 1N4007, and the two pin headers per the diagram above. Test with a blink sketch on GPIO27 at low PWM — the motor should buzz and the board should stay alive (if the board resets, the motor is drawing too much; drop to a smaller/proper pancake-motor current).
  3. Wire the sensors with Dupont leads: sound sensor OUT to GPIO35. The touch input is the CYD’s built-in XPT2046 touchscreen and needs no external wiring.
  4. 3D-print the shell: base/back for the CYD + speaker grille + touchscreen opening + screw bosses. Install M3 brass inserts, mount the screen, seat the speaker behind its grille, and hot-glue the vibration motor to the inner shell wall or floor so the whole body shakes.
  5. Firmware (v1 pet logic):
    • Face/eyes on screen: TFT_eSPI + XPT2046_Touchscreen
    • Clap/loud → sample GPIO35 ADC, trigger on a rising envelope threshold
    • Sounds → ledcWriteTone or DAC tones on GPIO26 (or .WAV via the amp)
    • Shiver → LEDC PWM burst on GPIO27 for ~300–600 ms when petted / happy
    • Mood state machine: idle → happy (touch) → surprised (touch or clap)
  6. Assemble & route USB-C out the back; fixate with the M3 + inserts.

8. Do NOT buy (for this version)

  • Raspberry Pi Pico / micro:bit — your CYD is the controller.
  • Battery / TP4056 / power switch — USB-C powers v1.
  • Separate touch sensor (TTP223 etc.) — the CYD touchscreen does this.
  • Audio amplifier module (PAM8403 / MAX98357) — the board has an on-board amp; only needed if you confirm your CYD lacks the speaker header.
  • PNP-power stage is optional; the standard NPN + flyback diode covers v1’s small motor.
