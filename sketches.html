Arduino sketches

Upload these in build order — each one adds one module and tests it before the next. Folder name must match the .ino name inside it.

How to upload. Open the .ino in the Arduino IDE, pick your board (esp32 for the normal DevKit, esp32c3 for the Mini), connect USB, and press Upload. Watch the Serial Monitor at 115200 baud to confirm each step works.

2. Pin defines at a glance

Every sketch uses the same pin numbers, so you wire once and never rewire:

DefineDevKit valueUsed by
SDA_PIN21OLED, ToF
SCL_PIN22OLED, ToF
MIC_PIN35clap / voice detection
TOUCH_PIN32petting the top
MOTOR_PIN27purring / nodding
SPK_PIN25audio (DAC, main sketch only)
ESP32 Mini / C3 users: the sketches target the normal DevKit. To use a C3 board, change the defines to SDA_PIN 8, SCL_PIN 9, MIC_PIN 2, TOUCH_PIN 3, MOTOR_PIN 7, SPK_PIN 6, and select the esp32c3 board. Note GPIO6 on the C3 is PWM-only (no DAC), so audio is a square wave. See the amp page for details.

3. Tuneable constants

The main sketch exposes thresholds at the top of the file so you can match it to your room without hunting through the code:

ConstantDefaultWhat it does
MIC_MIN_TRIGGER_DELTA250clap threshold — raise if it triggers on speech
MIC_COOLDOWN_MS2500wait after a clap before reacting again
MIC_SPEAKER_BLANK_MS800ignore the mic while the speaker plays
MIC_BASELINE_TRACKING0.01fhow fast the quiet background level is learned
TOUCH_MOOD_MS2600how long a petting stroke changes the mood
MOTOR_PURR_DUTY70motor speed when purring (of 255)
MOTOR_PWM_HZ20000above hearing — a healthy motor whine
